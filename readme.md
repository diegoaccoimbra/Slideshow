# Slideshow
A aplicação consiste em um slideshow automático e interativo, semelhante aos carrosséis que os serviços de streamings utilizam em sua página inicial. Ele exibe uma sequência de imagens de séries populares com controles de navegação automática e manual.

## 🎞️ Demonstração
- Acesse clicando [aqui](https://diegoaccoimbra.github.io/Slideshow/).

---

## 🛠️ Tecnologias utilizadas

- **HTML**
- **CSS**
- **JavaScript**

---

## ⚙️ Funcionalidades
- Navegação automática entre slides;
- Controle manual por botões interativos;

---

## 🧠 Como funciona

- A página HTML define 4 **radio buttons ocultos**, um para cada slide.
- As imagens estão organizadas dentro de `divs` que mudam de visibilidade com base no botão selecionado.
- O **JavaScript** manipula automaticamente a seleção dos radio buttons para gerar a transição automática.
- O **CSS** estiliza e posiciona os slides, botões e animações.
